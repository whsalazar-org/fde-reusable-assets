# FDE reusable assets

This repository hosts reusable documents produced from Forward Deployed
Engineering (FDE) engagements.

## Adding an asset

1. Remove client names, credentials, proprietary data, and other confidential
   information.
2. Place the document in a directory named for its asset type or topic.
3. Use a descriptive file name and include enough context for the document to
   be useful in future engagements.
4. Open a pull request that explains the asset's purpose and intended audience.

Only add material that is approved for reuse and distribution.
